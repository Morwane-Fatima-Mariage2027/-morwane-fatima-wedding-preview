# Morwane & Fatima — Wedding New

Nouvelle base indépendante du site de mariage de Morwane & Fatima.

## Principes

- construction neuve ; aucun code de l’ancien site n’est réutilisé ;
- mobile first ;
- HTML / CSS / JavaScript vanilla ;
- FR / EN / AR avec RTL ;
- RSVP Formspree ;
- direction papeterie éditoriale, ivoire + olive, avec touches indigo ;
- une seule photo du couple, attendue dans `assets/images/couple-original.jpg`.

## Structure

- `index.html` — longue invitation principale ;
- `styles/main.css` — système visuel et responsive ;
- `scripts/app.js` — enveloppe, countdown, RSVP, animations ;
- `translations/content.js` — traductions FR / EN / AR ;
- `assets/illustrations/` — illustrations au trait ;
- `assets/images/` — images autorisées uniquement ;
- `pages/` — réservé à d’éventuelles pages futures.
